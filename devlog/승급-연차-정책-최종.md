# 부캐영어(WorkMate English) — 승급 · 연차 정책 (최종안)

## 1. 직급 체계

사원 → 주임 → 대리 → 과장 → 차장 → 부장 → 이사

이사가 최고 직급이며, 더 이상 승급하지 않습니다.

## 2. 승급 조건 — 연속 출근일수

| 전환 | 필요 연속 출근일수 |
|---|---|
| 사원 → 주임 | 30일 |
| 주임 → 대리 | 60일 |
| 대리 → 과장 | 90일 |
| 과장 → 차장 | 120일 |
| 차장 → 부장 | 150일 |
| 부장 → 이사 | 180일 |

조건을 채우면 인사평가에 응시할 수 있습니다.

**인사평가 절차**
1. 그동안 대화한 동료·상사·거래처 각각에 대해 만족도(별점) + 개선 제안(선택) 입력
2. 유저의 실제 수준·약점 데이터를 기반으로 생성된 역량평가 문제 3개에 답변
3. 제출하면 **무조건 승진** (평가는 성장 기록용이며 합/불 판정용이 아님)

## 3. 연차 제도 (반차 폐지, 연차로 일원화)

연차는 성격이 다른 두 종류로 관리됩니다.

**(a) 직급 연차** — 현재 직급에 따라 주어지는 연차. 승급하면 이전 값은 사라지고 새 직급 기준 개수로 교체됩니다.

| 직급 | 직급 연차 |
|---|---|
| 사원 | 2개 |
| 주임 | 3개 |
| 대리 | 4개 |
| 과장 | 5개 |
| 차장 | 6개 |
| 부장 | 7개 |
| 이사 | 8개 |

**(b) 적립 연차** — 성실한 출근으로 직접 모은 연차. 출근 1일마다 성실 게이지가 1씩 채워지고, 5가 차면 자동으로 적립 연차 +1(게이지는 다시 0부터). 승급해도 사라지지 않고 계속 누적됩니다.

## 4. 결석 처리 (평일 기준, 주말 제외)

출근하지 않은 평일이 발생하면:

1. **직급 연차부터** 우선 1개 자동 차감 → 남아있으면 결석이 자동으로 커버되고, **연속 출근일수는 끊기지 않습니다**
2. 직급 연차가 없으면 **적립 연차**에서 1개 차감 → 역시 연속 출근일수 유지
3. 직급 연차·적립 연차가 모두 0인 상태에서 결석하면 → **연속 출근일수만 0으로 초기화**됩니다 (이미 쌓인 적립 연차·성실 게이지는 그대로 유지되며, 별도로 사라지지 않습니다)

## 5. 승급 시 처리 요약

| 항목 | 승급 시 처리 |
|---|---|
| 직급 연차 | 이전 값 폐기 → 새 직급 개수로 교체 |
| 적립 연차 | 그대로 유지 (별도 보너스 없음, 이미 직급 연차 자체가 매 승급마다 늘어남) |
| 연속 출근일수 | 0으로 초기화 (다음 직급의 더 큰 요건을 다시 채워야 함) |
| 성실 게이지 | 그대로 유지 |

## 6. 기존 기능과의 관계

- **외근 중 버튼**: 그대로 유지. 오늘 예정된 연락을 30분씩 미루는 기능으로, 하루를 끝내지 않으므로 이번 연차 정책과는 무관합니다.
- **반차 사용 버튼**: 삭제합니다. 외근 중 버튼이 "잠깐 피하기" 역할을 이미 하고 있어 반차라는 별도 개념은 불필요하다고 판단, "근무 중 / 연차 사용 / 퇴근 하기"로 단순화합니다.
