### QA 계정 초기화 방법 (재QA용)
- Supabase에서 본인 user_id 확인 후:
  ```sql
  delete from workdays  where user_id = '<UID>';   -- 대화·메시지·리포트 cascade
  delete from promotions where user_id = '<UID>';
  update user_profiles set job_rank='사원', level_evaluated_at=null, evaluation_started_at=null where user_id='<UID>';
  ```
- 체험(익명) 계정은 email이 null이라, 근무일수 많은 계정을 찾아 초기화:
  ```sql
  select u.id, u.email, u.display_name, count(w.id) as workdays, p.job_rank
  from app_users u
  left join workdays w on w.user_id = u.id
  left join user_profiles p on p.user_id = u.id
  group by u.id, u.email, u.display_name, p.job_rank
  order by workdays desc limit 20;
  ```
