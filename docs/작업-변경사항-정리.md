## 1. 첫 화면 · 로그인 구조 개편
- **첫 페이지 = 서비스 소개 랜딩(IntroPage)** 으로 변경. "체험해보기" → 온보딩 진입.
- **로그인/회원가입은 좌측 상단(사이드바) 계정 영역**으로 이동. 로그인하면 실명으로 사용.
- 인트로 게이트 연결 (`src/App.tsx` `entered` 상태 + OAuth 콜백 자동 통과).
- 관련 파일: `src/pages/IntroPage.tsx`, `src/components/shell/AccountButton.tsx`, `AccountModal.tsx`, `src/App.tsx`.

## 2. 로그인/인증 오류 수정 (`{"error":"인증 실패"}`)
- 원인: 브라우저에 남은 **만료된 토큰**을 계속 재사용하던 문제. (서버/환경변수 문제 아님)
- 조치: `src/lib/session.ts` `ensureSession` 재작성 — 항상 라이브 세션과 동기화하고, 만료 임박 시 자동 갱신, 없으면 익명 세션 재발급.
- 카카오 로그인: 예전 사이트(mero) 연결을 끊고 현재 사이트 기준으로 Supabase Redirect/Site URL 정리.

## 3. 윤경님 프론트 브랜치 머지
- `frontend-yk_2` → `main` 3-way 머지. 충돌 5건 해결(EmailView, ConversationView, nav-items, SettingsPage, vite.config).
- 백엔드/DB 파일 삭제 없이 보존 확인, 타입체크·빌드·스모크테스트 통과.

## 4. 머지 후 발견 버그 수정
- **안 읽은 메시지 뱃지(1)** 메신저 목록에 표시되도록 수정 (`ConversationList.tsx`).
- **이메일/메신저 낙관적 전송(optimistic send)** 과 윤경님 답장 힌트 UI 병합.
- **설정 페이지**: 윤경님 리디자인 유지 + "내 이름(표시 이름)" 섹션 보존 + 타입 오류 수정.

## 5. 웹푸시 알림 액션 버튼 (설계 확정)
- 카톡식 **인라인 입력은 웹 푸시 기술상 불가** → 확정안: 버튼 2개
  - **메시지 작성하기** (해당 대화 열기)
  - **외근중 (30분 뒤 재알람)**
- ※ 백엔드/서비스워커 실제 연결은 **남은 작업**(아래 참고).

## 6. 인사평가 · 승급 기능 (신규)
- 30일 근무 후 인사평가 → **무조건 승진**(사원→주임→대리→과장→차장→부장→이사).
- 인사평가 시 수집: **챗봇 만족도(별점) + 개선 제안**(서비스 개선용 저장) + **과거 교정 데이터 기반 유사 문제 3문항**.
- **프론트 배치(이번 반영)**: 리포트 아래 **nav "인사평가" 카테고리** + 전용 페이지 `/evaluation`
  - 30일 미달 유저가 눌러도 접근은 되되 **"아직 인사평가 기간이 아닙니다" + 진행바(N/30일)** 안내.
  - 30일 도달 시 **접근 가능 알림** + "인사평가 받기" → 평가 모달.
  - 홈 상단에도 대상이 되면 배너 노출(→ /evaluation로 이동).
- **QA용 임시 버튼**: 홈에 "30일 채우기(QA)" — 지난 30일 더미 근무 기록 일괄 생성(30일 게이트 테스트용).
- 파일: `server/promotion.js`(신규), `api/profile.js`(액션 라우팅), `src/lib/api.ts`, `src/components/promotion/PromotionModal.tsx`(신규), `src/pages/EvaluationPage.tsx`(신규), `src/pages/HomePage.tsx`.
- **DB(마이그레이션 실행 완료)**: `user_profiles.job_rank`, `user_profiles.level_evaluated_at` 컬럼 추가, `promotions` 테이블 신설.

## 7. 리포트 화면 개편 (이번 반영)

- 근무 시간 현황 섹션은 하단에 그대로 유지.
- 파일: `src/pages/ReportsPage.tsx`.

## ⚠️ 프론트에서 확인 / 이어받을 부분 (윤경님)
1. **답장 힌트가 어색하게 뜸** — `hints.ts`는 "LLM 연동 전 임시 키워드 힌트"라 "Thank you" 등에서 오작동.
   → 백엔드가 힌트를 생성하지만 `messages`에 저장하지 않아 프론트가 못 받음. **힌트를 메시지에 저장→스냅샷으로 전달→프론트에서 사용**하도록 연결 필요.
2. **리포트가 영어로 나옴** — 문법/단어 설명을 **한국어로** 주도록 리포트 프롬프트 수정 필요(`server/llm/prompts.js`).
3. **웹푸시 액션 버튼**(메시지 작성하기 / 외근중 30분 재알람) — 서비스워커 + 백엔드 재알람 스케줄 실제 연결 남음.
4. 이메일 디자인은 **정상 배포됨**(브라우저 캐시 이슈였음). 안 바뀌어 보이면 **Ctrl+Shift+R** 강력 새로고침.
